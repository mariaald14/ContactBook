#CONTACT BOOK

This is a simple Contact Book website I created using React and Vite for Project 2 Users can add contacts with a name or email and delete contacts they no longer need. 
I used React components, props, useState, and event handling to make the website work. I also used CSS to style the page and make it responsive for different screen sizes.
